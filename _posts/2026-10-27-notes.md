## [ProRL Agent: Rollout-as-a-Service for RL Training of Multi-Turn LLM Agents [arXiv:2603.18815]](https://arxiv.org/abs/2603.18815)

<div id="prorl" align="center">
  <img src="{{ '/assets/blogs/2026-10-27-notes/ProRL.png' | relative_url }}" alt="ProRL Agent" style="max-width: 100%; height: auto;">
  <p style="font-size: 0.9em; color: #666;">ProRL Agent</p>
</div>

ProRL Agent decouples rollout execution from RL training by encapsulating the entire rollout pipeline, from environment initialization to outcome evaluation, in an independent HTTP server that exposes APIs for trainers to invoke. The rollout server optimizes sandbox execution, manages agent runtime through three non-blocking queues with dedicated worker pools for initialization, execution, and evaluation, dynamically registers LLM servers, synchronizes model weights from the trainer, and routes LLM requests to the least-loaded server.
