## [Tracing Agentic Failure from the Flow of Success [arXiv:2607.12747]](https://arxiv.org/abs/2607.12747)

<div id="oat" align="center">
  <img src="{{ '/assets/blogs/2026-11-11-notes/oat.png' | relative_url }}" alt="OAT" style="max-width: 100%; height: auto;">
  <p style="font-size: 0.9em; color: #666;">OAT (Image Credit: https://arxiv.org/pdf/2607.12747)</p>
</div>

OAT proposes an unsupervised failure attribution method that trains a model only on successful trajectories without step annotations and identifies erroneous steps in failed trajectories at inference time. The key idea is to characterize the dynamic pattern in successful trajectories, and at inference time, assign each step in a failed trajectory an anomaly score based on its deviation from the learned normal flow. Specifically, OAT first collects successful trajectories for training, representing each action step by aggregating the token representations (e.g., hidden states from a particular LLM layer) within that step. Then it models the sequence of action representations as a continuous latent state path using Neural Controlled Differential Equations ([Neural CDEs](https://arxiv.org/abs/2005.08926)). The model is trained to minimize the reconstruction error between the original action representations and those recovered from the corresponding latent states.  At inference time, this reconstruction loss serves as the anomaly score for identifying potentially erroneous steps in a failed trajectory.

## [Contrastive Language Models](https://contrastive-lm.notion.site/)

<div id="clm" align="center">
  <img src="{{ '/assets/blogs/2026-11-11-notes/clm.png' | relative_url }}" alt="CLM" style="max-width: 80%; height: auto;">
  <p style="font-size: 0.9em; color: #666;">Contrastive Language Models (Image Credit: https://contrastive-lm.notion.site/)</p>
</div>

 Contrastive Language Models (CLMs) is a new class of System One model trained with a contrastive learning objective that connects states and actions. Each state is pulled toward the ground-truth action that was taken and pushed away from all others. A CLM consists of a state encoder and an action encoder, both of which map their respective inputs into a shared embedding space, where the score of a state–action pair is computed as the cosine similarity between their embeddings. Each encoder consists of a frozen LLM backbone followed by a trainable projection head. CLM takes the hidden state of the final token, normalize it, and pass it through a MLP projection head. At inference time, given the current state and a set of candidate actions, CLM scores each action by how well its embedding aligns with the state embedding and selects the highest-scoring action.

 CLM is pretrained on a large-scale question–answer dataset containing ~60M pairs from Nemotron DQA, where each question is treated as a state and its corresponding answer as an action. In other words, question-answer relation is a one-to-one mapping. A bidirectional InfoNCE loss is leveraged at this stage to simutaneously maximize (1) the probabiltiy of selecting the correct answer a<sub>i</sub> given a question s<sub>i</sub>, and (2) the probability of identifying the corresponding question s<sub>i</sub> given its answer a<sub>i</sub>. The pre-trained checkpoint is then mid-trained on ~30M synthetic hard negatives generated by Gemini 2.5 Flash-Lite for a subset of Nemotron DQA questions. These incorrect answers, denoted as h<sub>i,k</sub>, turn the original question s<sub>i</sub> into a multi-choice question and their cosine similarities with the corresponding questions are minimized. Finally, CLM is post-trained on ~1M agent trajectories from the Agent Data Protocol (ADP) dataset, Endless-Terminals, and LiteCoder-Terminal-SFT. Each trajectory step is represented as a state–action pair, where the state contains the agent’s current context and the action corresponds to the decision taken at that step.
